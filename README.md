The project is structured in the following way: 

kuramoto_model.py: Includes all the Kuramoto-model specific functions. Simply substitute with the equivalents for whatever other model might be of interest to apply the rest of the code. 

shift_matrix.py: Contains all the functions for shift matrix generation.

shifted_dynamics.py: Contains all the functions for observing shifted dynamics. Uses functions provided in kuramoto_model.

plot.py: contains the functions for plotting the generated data
